# Licenses in this repository

**This repository: MPL-2.0.** wavicle is a substantial derivative of the
WavPack C reference, and every file carries Exhibit A and the SPDX tag
`MPL-2.0`, per the
[license posture brief](../mere/design_docs/2026-08-22_license_posture_brief.md)
of 2026-08-22 (mere `design_docs/2026-08-22_license_posture_brief.md`). The
full text is in [`LICENSE`](LICENSE).

This file is the provenance ledger. It is the authority for what the relicense
tool (mere `scripts/relicense_headers.py`) skips: the backtick-quoted paths in
the **Retained licenses** table are never touched. Provenance comes before
license: a file gets Exhibit A only if Mark wrote it.

## Retained licenses

Third-party code keeps its own license and its own notices. Nothing here is
relicensed, and nothing here receives a Merely copyright line.

**None.** No verbatim third-party source is vendored into this repository. The
reference implementation was read and ported, never copied in; the ports are

## Derivatives carrying MPL-2.0 with an upstream notice retained

These are **not** skipped. Each file receives Exhibit A and Mark's copyright
line, and every upstream notice is kept verbatim. Applied with
`--retain-notice`.

wavicle's codec modules are Rust ports of the C reference at
[`dbry/WavPack` tag `5.9.0`](https://github.com/dbry/WavPack/tree/5.9.0),
BSD-3-Clause, `Copyright (c) 1998 - 2025 David Bryant` / Conifer Software.
They are Mark's own Rust — no upstream source is copied — but the algorithms,
constants, and bit-exact arithmetic are transcribed from it, which makes them
substantial derivatives under the brief's rule rather than independent work.

`src/error.rs`, `src/lib.rs`, `tests/conformance.rs`, `tests/fixtures/gen.py`
and `fuzz/fuzz_targets/decode.rs` are Mark's own and derive from nothing; they
take the default with no notice to retain.

The upstream notices sit inside each module's `//!` documentation rather than
above the header, so the tool's `--retain-notice` had nothing to lift: the
header was prepended above the docs and every `Copyright (c) David Bryant`
line stayed exactly where it was. `PROVENANCE.md` maps each module to the
reference files it used and is updated whenever a port lands.

BSD-3-Clause permits relicensing a derivative provided the notice is retained,
which `ATTRIBUTION.md` and the in-file `//!` notices do. Clause 3 (no
endorsement) is honored by the crate's name and by the README's statement that
wavicle is not affiliated with or endorsed by the WavPack project. Ruled on the
brief's substantial-derivative precedent: tucket keeps MeshCore's MIT notice,
cambium and meristem go MPL-2.0 with the Apache notice retained, and luggage
keeps the Tauri/CrabNebula lines.

`wavicle` is published (0.1.0, 2026-07-18, MIT OR Apache-2.0); that version
keeps its grant permanently and MPL-2.0 ships at the next functional bump, per
the sweep plan's invariant 8.

**This section is deliberately not the skip list.** The tool reads only the
`## Retained licenses` table above. Adding a path here documents a disposition;
it does not exempt the path from receiving a header.

## Exceptions under the fork/vendor criterion

**None.** The brief's §4 test — a crate stays MIT OR Apache-2.0 only when a
third party would need to *modify or vendor* it rather than merely link it —
admits nothing, and as of 2026-08-22 there are no exceptions anywhere. wavicle
was never proposed for one; it takes the default.

## How to add a file from elsewhere

1. Do not delete or rewrite the upstream copyright or license notice, ever.
2. Add its path to **Retained licenses** above with its license, upstream URL,
   and where its notice text lives. The tool then skips it automatically.
3. If it is a substantial derivative rather than a verbatim import, the brief's
   rule is MPL-2.0 on the derivative *with the upstream notice retained* —
   record it in the section above with that disposition, and add its row to
   `PROVENANCE.md` so the mapping to reference sources stays complete.
4. Never add `license-file` to an owned manifest.
5. Re-run `python ../mere/scripts/relicense_headers.py --repo . --audit` and
   confirm the owned source count moved by exactly what you expected.
