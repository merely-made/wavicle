# wavicle

A pure-Rust WavPack v5 codec: lossless, bit-exact decode and encode with no C
anywhere in the build graph.

## Status (2026-08-12)

Feature-complete for its declared scope; published on crates.io as
`wavicle` 0.1.0 (2026-07-18).

- Both directions are lossless and bit-exact: decode and encode of 16/24/32
  bit integer and 32-bit float, mono and stereo, any input length (long data
  splits into independent blocks). Float survives a BLAKE3 identity check
  over decoded bytes in both directions, including signed zero, denormals,
  and NaN payloads.
- Every milestone is gated bit-for-bit against the reference
  `wvunpack`/`wavpack` CLI at tag 5.9.0; the decoder is fuzzed and never
  panics on hostile input.
- Multi-term decorrelation landed 2026-07-18, so encoded sizes roughly match
  the reference encoder.
- `#![forbid(unsafe_code)]`, std-only, zero runtime dependencies, builds for
  wasm32. Decode is the default feature; `encode` is additive.

In scope: the WavPack v5 stream, versions 0x402..=0x410 read, 0x410 written.
Out of scope, rejected with clear errors: DSD, hybrid/lossy modes and `.wvc`
correction files, more than two channels, pre-4.0 streams.

The remaining planned milestone is consumer-side wiring in the sibling Hocket
repo, not work here. The founding plan and conformance-oracle method live in
[design_docs/2026-07-15_wavpack_codec_plan.md](design_docs/2026-07-15_wavpack_codec_plan.md).

## Use

First consumer is [Hocket](https://github.com/merely-made/hocket), which
stores audio phrases as `.wv` entries. Usable from any Rust project
(including wasm) that needs WavPack without a C toolchain.

```sh
cargo add wavicle                      # decode only (default)
cargo add wavicle --features encode    # also write .wv
```

API entry points: `decode_stream` (decode); `encode_int` / `encode_float`
with `EncodeParams` (encode); block inspection via `Blocks`, `BlockHeader`,
`StreamInfo` with no features. `cargo test` runs the golden-vector and
round-trip tests; reference-CLI conformance runs in CI.

## Relationship to WavPack

WavPack is David Bryant's audio compression format
([wavpack.com](https://www.wavpack.com), BSD-3-Clause). This crate is an
independent Rust implementation of the WavPack v5 bitstream, written for
interoperability, not affiliated with or endorsed by the WavPack project.
Portions derive from the reference implementation at tag 5.9.0; see
[ATTRIBUTION.md](ATTRIBUTION.md) and [PROVENANCE.md](PROVENANCE.md).
